# 🚀 AlgoVisualizer Pro  
### *Interactive • Intuitive • Insightful Algorithm Learning Platform*

AlgoVisualizer Pro is a modern, high-performance web application designed to help students, developers, and interview aspirants **understand algorithms visually**. It brings complex data structures and algorithms to life through **smooth animations, step-by-step simulations, performance metrics, and interactive controls**.

---

## 🎯 Features

### 🔹 Rich Algorithm Library
- Sorting: Bubble, Selection, Insertion, Merge, Quick, Heap  
- Searching: Linear, Binary  
- Trees & Graphs: BFS, DFS, Traversals  
- Advanced Topics: Sliding Window, Two Pointer, Prefix Sum, Hashing  
- More algorithms added continuously

### 🔹 Real-Time Step-by-Step Visualization
- Watch every operation animated  
- Compare, swap, and pointer movement highlights  
- Speed control: slow-motion to fast-forward  
- Pause, resume, restart dynamically

### 🔹 Clean & Responsive UI
- Built with React + Tailwind  
- Smooth GSAP-based animations  
- Fully optimized for mobile, tablet, and desktop

### 🔹 Performance Insights
- Shows time and space complexity  
- Tracks operation counts (comparisons/swaps)  
- Helps understand efficiency differences

### 🔹 Learning-Focused Experience
- Clear visual cues  
- Intuitive algorithm flow  
- Designed for beginners and advanced learners alike

## 📦 Installation

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/yourusername/algovisualizer-pro.git
cd algovisualizer-pro
```
### 2️⃣ Install Dependencies
```bash
npm install
```
### 3️⃣ Start Development Server
```bash
npm run dev
```
